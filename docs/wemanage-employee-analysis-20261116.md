# 员工分析与用量诊断

人员页面新增同等已过时长的请求、总 Token、非缓存输入、错误请求、缓存比例和错误率对比。保留零对照、空数据和接口失败状态。项目与请求模型同时展示请求占比和 Token 占比。缓存不重复计入总量。

分析依据展示可检索文本比例、可见日报日期数、有调用但无可见日报的日期、问题线索和可复用方法线索。缺少日报可能来自生成状态或隐私过滤，不能推断工作缺失。问题线索没有当前完成状态，须人工核对。

个人页面可按所选员工和日期跳转到会话原文、使用诊断和内容风险核查。画像生成模板增加交付物验证状态、协作依赖和需要的支持，每条结论要求来源，不推断岗位、能力或绩效。既有报告保留；点击生成才使用模型额度。

本次同步还包含既有历史用量、Fusion 分发、使用诊断及存储观察功能的代码。公开仓库仅提供实现与合成测试，不包含真实员工日志、分析摘录或运营账单。
